u-boot 上游（upstream）实验构建
==============================
源码:        u-boot v2026.10（GitHub u-boot/u-boot archive tarball）
target:      本仓库自建 zerot1-rk3588_defconfig（src/zerot1-rk3588_defconfig）
             板级 dts: src/rk3588-aiot3588a.dts（复用 rk3588-nanopc-t6.dtsi）
             U-Boot 侧 u-boot dtsi: src/rk3588-aiot3588a-u-boot.dtsi
             补丁: src/0001-bootflow-scan-all-partitions.patch
                   （cmd/bootflow.c 去掉 BOOTFLOWIF_ONLY_BOOTABLE，让 bootstd
                     扫描全部 GPT 分区，从而找到 boot 分区的 extlinux.conf）
BL31:        rk3588_bl31_v1.53.elf（Android SDK rkbin）
ROCKCHIP_TPL: rk3588_ddr_lp4_2112MHz_lp5_2400MHz_v1.20.bin
              （通用 rkbin，LPDDR4 2112MHz / LPDDR5 2400MHz；
               取 /home/zero/work/rk35xx-android14/rkbin/bin/rk35/）
工具链:      Android prebuilts gcc-arm-10.2 aarch64-none-linux-gnu-
构建日期:    2026-11-09

产物:
  idbloader.img         223232 B  (binman: TPL + SPL；刷 eMMC 0x40 扇区)
  u-boot.itb           1323520 B  (FIT: BL31 + u-boot + DTB；刷 eMMC 0x4000 扇区)
  MiniLoaderAll.bin     395712 B  (LDR 封装；由 scripts/make-ldr-loader.sh 用
                                   boot_merger 的厂商 ini 流水线生成：NEWIDB=true，
                                   CODE471=DDR、CODE472=usbplug、LOADER=DDR+SPL，
                                   boot_merger 自动生成 RKNS FlashHead)

关键配置:
  CONFIG_BAUDRATE=1500000（与本板串口 ttyS2 一致）
  CONFIG_BOOTCOMMAND="bootflow scan -lb mmc0"
  CONFIG_BOOTSTD=y / CONFIG_BOOTMETH_EXTLINUX=y / CONFIG_FS_EXT4=y
  CONFIG_SYS_MMCSD_RAW_MODE_U_BOOT_SECTOR=0x4000（SPL 从 0x4000 扇区加载 u-boot.itb）
  PCIe/NVMe/EFI bootmgr 均关闭（U-Boot 阶段不需要，且本板 PCIe link fail 会卡住）

引导方式（不写死分区）:
  上游 u-boot 用 bootstd 扫描所有 bootdev（eMMC/SD/USB/网络），
  在 boot 分区找到 /extlinux/extlinux.conf 后按其 label 启动；
  root 由 extlinux.conf 的 append（root=UUID=...）决定。

LDR 封装说明（2026-11-09 实证）:
  - 关键点：`uf` 的 loader 槽必须是 "LDR " 容器。用 boot_merger 的
    `pack -1/-2/-3` 手工拼会得到 "BOOT" 魔术的容器 ⇒ uf 在 Download Boot 阶段失败。
  - 正确做法：走厂商 ini 流水线（NEWIDB=true），由 boot_merger 生成 LDR 容器并
    自动生成 RKNS FlashHead。实现在 `scripts/make-ldr-loader.sh`：
      SPL   = spl/u-boot-spl.bin
      DDR   = rk3588_ddr_lp4_2112MHz_lp5_2400MHz_v1.20.bin
      USBPLUG = rk3588_usbplug_v1.11.bin
  - 已上板验证：`sudo upgrade_tool_2.45 uf output/fnos-aiot3588a-v1.1-update-20261109.img`
    一条命令刷写成功，串口日志：
      BL31 v1.53 → U-Boot 2026.10 → bootstd 扫描 mmc0 →
      `0 extlinux ready mmc 4 mmc@fe2e0000.bootdev.part /extlinux/extlinux.conf`
      → 启动 fnOS 6.18.18-trim 内核。
